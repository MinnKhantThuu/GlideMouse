# Architecture

`MouseCore` is a platform-independent typed configuration, profile resolver, button/touch recognizer and scrolling module. `NativeBridge` owns private MultitouchSupport ABI, a fixed 128-frame ring and bounded process-group automation. `GlideMouse` composes native adapters, lifecycle, action execution and SwiftUI settings. There is no backend or root daemon.

The InputRuntime owns a dedicated CFRunLoop thread. UI edits validate and save JSON, then enqueue a value snapshot. Input callbacks classify and suppress synchronously without UI/disk/network/shell work. UI-dependent actions go to the main actor with generation checks. Desktop left/right shortcut batches, scrolling and pointer drag events post on the input thread so settings layout does not delay desktop navigation. A short lock protects only loop/epoch handles. The timer drops to 4 Hz when idle and runs at 120 Hz only while timed recognition, smoothing or touch delivery is active.

Unmapped primary/secondary buttons pass through immediately. Optional primary double/hold bindings temporarily buffer the original events. Unrecognized short clicks replay at the session event layer with original locations, modifiers and click counts; movement beyond three points restores native dragging. A configuration/focus reset flushes buffered events and balances a replayed drag. Primary single-click, triple-click, drag, wheel and chord bindings remain unavailable so basic control stays accessible. Enabled auxiliary-button bindings own balanced press/release input; unmapped events stay native. Our event source carries a constant tag and own events are ignored before recognition. Native continuous scrolling cancels smoothing and quarantines touch taps until all contacts lift. The touch bridge never starts on the built-in trackpad and accepts only an external family-112 mouse candidate when a Magic Mouse is identified by HID metadata and the user explicitly enables touch.

Anonymous global events never resolve persisted device overrides. Touch handles are session identities, not stable device identities; they group gesture traces but do not activate persisted per-device rules. The resolver implements app+device > app > device > global for future adapters with proven identity. Disabled mappings and profile pause stop inheritance.

Any profile/focus/pause/sleep/device/permission change cancels recognizers, smoothing, drag and commands. Event-tap timeouts have three bounded recovery attempts. Emergency ⌃⌥⌘Esc and the menu bar can pause; the hotkey is not claimed to survive input-thread failure. Reconnecting HID devices triggers refresh notifications. macOS itself tears down a dead process's event tap; forced termination may still leave synthetic state, so crash recovery requires hardware beta testing.

Settings use schema 2, atomic writes and a validated last-known-good backup. Invalid originals are archived before replacement. Import is previewed; engine/touch/update flags are reset and imported shell/Shortcuts actions disabled. Shells have a minimal documented environment, home-directory default cwd, one concurrent command, 1–60 s timeout, SIGTERM then SIGKILL group cleanup. No command output is logged.

UI resources use a string catalog (English/Burmese/Simplified Chinese), semantic macOS colors and native controls. Accessibility labels accompany icon controls. Reduce Motion works by having no autonomous gesture animation. A native render harness provides actual SwiftUI snapshots; it is separate from end-user flow automation and VoiceOver acceptance.
