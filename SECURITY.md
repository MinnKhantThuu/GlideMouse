# Security

Report permission, event ownership, configuration import or command-execution issues privately to the maintainer at minnkhantthu.ucsy@gmail.com. Use GitHub Issues for ordinary reproducible bugs. Do not publish credentials, private keys, user settings or sensitive traces.

Automation is opt-in, imported automation starts disabled, output is not captured, and commands run in isolated process groups with timeouts. Profile JSON is size-bounded, strictly decoded and validated. Core input features use no network. Sparkle handles signed updates only after an HTTPS feed and verification key are configured. Private touch ABI and event attribution remain compatibility gates.
